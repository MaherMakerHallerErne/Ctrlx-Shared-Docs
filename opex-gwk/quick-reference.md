- Config path: Solutions → `he-ctrlx-app-commgo/appdata.json` (restart after edits)
- Output config: Solutions → `he-ctrlx-app-commgo/outputs.json` (buffering & HTTP posting)
- Data Layer nodes: `he/commgo/app/tool1/command`, `state`, `lastResult`
- Buffer status: `he/commgo/buffer/status` (queue, disk space, transmission stats)
- Enable pulse: each tightening requires a new enable rising edge
- Logs: Diagnostics → Logbook (filter by app source)
- Error codes: [Error Codes Reference](./error-codes.md) (negative values block Enable/Disable)
- Common fields: `ParameterSetName`, `TorqueTarget`/Min/Max, `AngleTarget`/Min/Max
