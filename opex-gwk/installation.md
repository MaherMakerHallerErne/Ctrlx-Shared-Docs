## Install
1. Update ctrlX to OS V3.6.2.
2. Navigate to Settings → Apps → "Install from file".
3. Allow unknown sources if prompted.
4. Select the `he-ctrlx-app-commgo` snap matching architecture (arm64 / amd64).
5. Confirm the sidebar shows "GWK Operator App" and the dashboard widget appears.
